## 📖 Overview

InspiCrete-OrbFX is a modern graphics enhancement platform built with **C++20** and **Qt 6**, designed to provide high-performance, real-time image processing and post-processing effects.

Unlike GPU vendor-specific software, InspiCrete-OrbFX aims to deliver a unified graphics enhancement experience across NVIDIA, AMD, and Intel GPUs.

The long-term goal is to become a modern, extensible, and user-friendly graphics enhancement platform for gamers, creators, and professionals.

## ⚡ Build

### Requirements

- Windows 11
- Visual Studio 2022
- Qt 6
- CMake
- Git

### Clone

```bash
git clone https://github.com/gatsu-hy/InspiCrete-OrbFX.git
```

### Build

```bash
mkdir build
cd build

cmake ..

cmake --build . --config Release
```
